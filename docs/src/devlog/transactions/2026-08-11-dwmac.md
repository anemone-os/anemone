## 边界

本 transaction 记录 R0/R1 acceptance，以及后续逐 Gate 的实现、review、validation、停止与 cutover 事实；不复制
RFC target 或实施计划。当前唯一授权是 R1 Gate 1：保持 JH7110 DWMAC4 可见行为，将 shared 逻辑留在
`net::dwmac`，由 `net::dwmac::dwmac4` 与 `net::dwmac::dwmac1000` 分别拥有并注册对应 `Driver`，并建立
Loongson 2K1000 irqchip-owned `IrqSense` source truth 与 one-shot request expectation。Gate 1 不接入
DWMAC1000 hardware、不发布新 netdev 能力、不改变 current contracts，完成后必须停止。

**Boundary check:** 该修订仍位于 RFC Implementation Boundary 内：同一 DWMAC owner 内的 variant-local
module split 与 narrow shared helper，未扩大 userspace ABI、current contract 或跨 owner handoff。

### Gate 1 software implementation and review - 2026-08-12

**Implementation:**

- `driver/net/dwmac/mod.rs` 现在只拥有 common probe input、frame adapter、publication/shutdown helper。
- `driver/net/dwmac/dwmac4/mod.rs` 拥有 DWMAC4 `Driver`、match table、registration 和既有 JH7110
  clock/reset/PHY/descriptor path；`dwmac4` concrete register/descriptor state 未泄漏到 common。
- `driver/net/dwmac/dwmac1000/mod.rs` 拥有 DWMAC1000 `Driver`、match table 和 registration；probe 在
  Gate 1 明确返回 `NotSupported`，没有 DWMAC1000 hardware side effect。
- `request_irq`/`request_irq_selected` 增加 assertion-only `Option<IrqSense>`；prepare -> compare ->
  commit/unmask 顺序保持 fail-closed，mismatch log 记录真实 hwirq/expected/actual；shared frame adapter
  只消费 `bool` recheck capability，不暴露 concrete pending cause 表示。

**Independent review:** reviewer 未发现 Apollyon/Keter；owner-local module registration 与 common
helper 边界闭合。初始 Euclid（mismatch 日志固定打印 `hwirq=0`/`actual=None`）已在上述 IRQ 路径修正；
common 先读取 named `macirq` 供 input/logging，publication 时再次通过窄 selector 请求，保留为 Safe 的
局部重复，不改变行为。
