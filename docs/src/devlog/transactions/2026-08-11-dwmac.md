### R2 Gate 1 validation revision and closure - 2026-08-12

**Decision:** 用户明确授权关闭 Gate 1，并指定 RiscV validation 保持 Not Run。接受 R2 validation staging

**User-run 2K1000 evidence:** 同次实机启动提供以下可核验事实：

- ICU init readback：`EDGE=0x1f00000000000`，精确置位 source 44..48；`POL=0xf000`，精确置位 source
  12..15。该结果与 owner-local `IrqSense` table 的 DMA edge 与 GMAC active-low target 完全一致；随后
  controller/pending window 记录为 `0x1fe01400/0x100` 与 `0x1fe01040/0x110`。
- `ethernet@40040000` 与 `ethernet@40050000` 均以
  `["snps,dwmac-3.70a", "snps,arc-dwmac-3.70a"]` 注册到 platform bus。
- 两个 node 均由 variant-local `dwmac1000` Driver 匹配，并打印“backend registered but not enabled until
  Gate 2”；probe 随后返回 expected `NotSupported`。这证明 Gate 1 在任何 DWMAC1000 register/DMA/PHY/IRQ
  transaction 或 netdev publication 前 fail closed；该错误日志不是 Gate 1 failure。

**Evidence boundary:** 2K1000日志不证明 DWMAC1000 register family、DMA reset、descriptor、MDIO/PHY、CSR5、
traffic 或 production attach；这些仍属于 Gate 2--3。RiscV/VisionFive 2 hardware regression为Not Run，

**Review / architecture friction:** 独立 review确认 exact masks关闭`TARGET-005`/`ISSUE-003`的controller

## Gate 2 software protocol slice - 2026-08-12

**Implementation:** 在 `net::dwmac::dwmac1000` owner 内加入 private `protocol` module，固定 Linux
legacy normal descriptor 的 16-byte `des0..des3` layout：TX/RX OWN 在 `des0`，TX first/last/interrupt、
ring-end 和 11-bit buffer length 在 `des1`，buffer address 在 `des2`；同时加入 checked half-open
32-bit DMA admission、bounded descriptor-ring arithmetic 和 CSR5 `0x1ffff` legal W1C cause mask。模块
只提供 pure construction/mask helpers 与 inline owner-local KUnit，不执行 MMIO、DMA allocation、IRQ、PHY
transaction 或 netdev publication。

**Review:** 独立 review 对照 Linux 6.6 `descs.h`/`norm_desc.c` 确认 normal word/bit layout、CSR5 mask 和
`[start, end) <= 4GiB` checked arithmetic；未发现 Apollyon/Keter。残余约束是 helper 尚未接入 production
ring 或硬件 probe，不能单独证明 OWN transition、PHY/Route A 或 device-cause readback。

**Validation:** `just fmt kernel --check` passed；`just build --preset 2k1000-la64-release` passed（含
KUnit、DTB materialization 和 raw image）；`git diff --check` passed。既有 DTS warnings 和 unrelated
Rust warnings unchanged。Gate 2 仍 **Stopped / Not Cut Over**，ISSUE-001/002/004/005 保持 Open；不更新
current contracts，不进入 Gate 3。
