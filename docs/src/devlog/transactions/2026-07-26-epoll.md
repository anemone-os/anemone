## Scope

依次用 0A terminal liveness、0B observer/pipe、0C timerfd noirq 与 0D TTY handoff 证明共同
subscription protocol 可行。Stage 1 已在 Stage 0 独立关闭后完成 resolution，并在新的明确授权下
原子完成；Stage 2 保持 Outline。初始授权覆盖 0A、0B；后续授权覆盖 0C、0D、`0 -> 1`
resolution gate 与 Stage 1 实现。当前事务停在 Stage 1 closure，不覆盖 Stage 2 resolution 或实现。

**Result:** Closed。按开发者要求把原 `fs/iomux.rs` 目录化为

**Consumer lifecycle:** `IomuxWaitRound` 线性拥有本轮 `Latch`、`LatchTrigger`、observer
acceptance 与 route origin。正常与 Drop fail-close 路径都先把唯一 callback-acceptance bit 从

concurrency review 发现临时强引用可能在 source lock 内成为最后 observer owner。最终实现改为只读
